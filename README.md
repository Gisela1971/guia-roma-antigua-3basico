# Guía interactiva: La civilización romana

## Descripción
Esta guía digital está pensada para estudiantes de 3° básico. Presenta información clave sobre la civilización romana, actividades para practicar y respuestas para apoyar el aprendizaje.

## ¿Cómo usar esta guía?
- Lee cada sección con atención.
- Responde las actividades antes de mirar la respuesta.
- Usa los botones de “Ver respuesta” para comprobar tus respuestas.
- Puedes imprimir la guía o explorarla en el navegador.

## Contenido
- La ciudad de Roma
- La vida cotidiana de los romanos
- Construcciones importantes
- Dioses y creencias
- El Imperio Romano
- Actividades con respuestas
